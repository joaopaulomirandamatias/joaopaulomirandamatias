## Pesquisa científica aberta

Dezesseis manuais em slides que cobrem uma pesquisa inteira, da pergunta ao artigo publicado e registrado. Cada um tem **domínio próprio, repositório público e capturas reais datadas**, e todos são **CC BY 4.0**. As mesmas instruções viram *skills* executáveis no [plugin para Claude Code e Codex](https://github.com/joaopaulomirandamatias/pesquisa-mirandastech).

> **[Laboratório 3D](https://manual.mirandastech.com.br/lab/)** — os dezesseis manuais numa torre navegável no navegador, com protótipo WebXR. React na interface, Three.js na cena.

### O plugin

Quatro agentes (Pesquisador, Metodólogo, Orientador de uso de IA, Bibliotecário do Zotero), vinte skills ligadas aos manuais e um conector local do Zotero. O estudante decide; a IA formula, registra e só fecha uma fase com evidência.

```
/plugin marketplace add joaopaulomirandamatias/pesquisa-mirandastech
/plugin install pesquisa@mirandastech
```

Disponível também no diretório de plugins do Codex, em Educação e pesquisa.
